Hazırlanıyor…
Konuşmaya başla Mikrofona dokun, konuş. Duyduğunu karşı dile çevirip sesli okur, sonra sırayı karşı tarafa verir. Telefonu ikinizin arasına koyman yeterli.
Başlamak için dokun

Ayarlar

Hoparlörden çalıştırırken ilk seçenekte kal; yoksa telefon kendi sesini duyup kendini çevirmeye başlar.

Çeviri kaynağı

Google doğrudan erişimi engellenirse devreye girer. Adreste {url} yazan yere hedef adres konur; {url} yoksa adresin sonuna eklenir.

Anahtar: console.cloud.google.com/apis/credentials → API anahtarı oluştur → “Cloud Translation API”yi etkinleştir. Aylık ilk 500.000 karakter Google’ın kredisiyle karşılanıyor, sonrası ücretli; fatura kartı istiyor.

Anahtar: aistudio.google.com/apikey → “Create API key”. Ücretsiz kotası var. Model adı zamanla değişiyor; hata alırsan güncel adı yaz.

Geçmiş

Bilinmesi gerekenler

Sayfa https:// üzerinden açılmalı; dosyaya çift tıklayarak (file://) açarsan tarayıcı mikrofona izin vermez.

Yerel çeviri ve yerel ses tanıma yalnız masaüstü Chrome/Edge’de var. Telefonda ses tanıma Google’ın sunucusuna gider, yani internet ister.

Sesten dil tespiti tarayıcıda mümkün değil: uygulama sırayla dinler. Sen konuşunca sıra karşı tarafa geçer. Yanlış dilde konuşulursa metinden anlayıp çeviri yönünü düzeltir.
